# مرغ دونی - Fixed Media Edition

این نسخه از پروژه موجود اصلاح شده و ظاهر اصلی آن حفظ شده است.

اصلاحات:
- Voice Chat از WebRTC با signaling فعلی Socket.IO استفاده می‌کند.
- دوربین به همان PeerConnection اضافه شده و remoteVideo برای حریف اضافه شده است.
- درخواست «بازی جدید با همین حریف» دارای درخواست، قبول و رد واقعی است و بازی جدید را بدون reload می‌سازد.
- GIF و استیکر/رسانه چت از طریق Socket.IO برای همه اعضای اتاق broadcast می‌شوند.
- ارسال فایل در چت اضافه شده: عکس، GIF و فایل‌های معمولی تا ۳MB؛ فایل‌های اجرایی مسدود هستند.
- تصاویر کارت‌ها ۲ برابر و با sharpen ملایم پردازش شده‌اند.
- ساختار و ظاهر فعلی تا حد ممکن حفظ شده است.

نکته مهم درباره دوربین:
WebRTC برای اتصال اینترنتی واقعی ممکن است علاوه بر STUN به TURN نیاز داشته باشد، مخصوصاً پشت NATهای سخت. این نسخه signaling و track انتقال تصویر را کامل کرده، اما بدون TURN نمی‌توان تضمین کرد که در همه شبکه‌ها تصویر از یک حریف به حریف دیگر برسد.

اجرا:
1. npm install
2. node server.js
3. برای تونل: npx runlocal 3000
