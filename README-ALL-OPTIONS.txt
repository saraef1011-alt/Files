مرغ‌دونی — نسخه همه قابلیت‌ها

قابلیت‌ها:
- Voice Chat با WebRTC
- Camera با WebRTC و نمایش تصویر حریف
- بازی جدید با همان حریف
- خروج بدون Reload
- چت متنی
- استیکر
- GIF واقعی و متحرک که از طریق Socket.IO برای اتاق ارسال می‌شود
- ارسال فایل تا 5MB (به‌جز فایل‌های اجرایی خطرناک)
- کارت‌های تصویری با کیفیت بالاتر

اجرا:
1) npm install
2) node server.js
3) در CMD دوم: npx runlocal 3000
